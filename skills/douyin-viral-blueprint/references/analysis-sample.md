# 写作样本

下面是**格式与颗粒度的基准**，数据编的、彼此自洽，不要照抄内容。
动笔前先 `node check.mjs <目录> --contract` 看字段清单与取值范围。

## 过程（4–8 步）

一步只推一件事，写成「因为 X → 所以 Y」。X 必须是指针，不是数值。

```
1. 因为 `视频.比例.藏赞比` 明显高于同类工具型内容，而 `视频.比例.转赞比` 很低
   → 观众在把它当资料存，不是当谈资转
2. 因为 `评论.聚类.簇` 里最大那簇整簇都在复读同一句话要模板
   → 资料钩子确实接住了需求，不是自说自话
3. 因为 `评论.聚类.水评率` 极低、`评论.覆盖省级行政区` 分散
   → 讨论是真实提问，不是刷的
4. 因为 `画面.拼图` 第 1 格是真人半身、第 6 格已切到整屏录屏
   → 这是「人讲 + 屏演」双层结构，与 `内容轴.切镜每分钟` 偏高互相印证
5. 因为 `内容轴.首句秒` 偏晚、`密度曲线` 最低桶落在报错段
   → 最可能掉人的是开场与报错段，不是内容本身
```

## 判断八项

八项固定：赛道 / 形态 / 特点 / 人群 / 开场 / 结尾 / 选题位 / 论点。
每项一句结论 + 依据指针，**指针里不写数值**。

```json
{ "项": "赛道", "评价": "信息", "结论": "办公效率教学，面向 Excel 使用者讲公式与条件格式，不是泛 AI 科普。", "依据": ["视频.话题", "视频.文案"] }
{ "项": "形态", "评价": "好",   "结论": "八分半「真人讲解 + 整屏演示」双层结构，真人只占小部分，主体是操作画面。", "依据": ["内容轴.切镜每分钟", "拼图-01.jpg 第 1 格", "拼图-01.jpg 第 9 格"] }
{ "项": "开场", "评价": "好",   "结论": "提问式痛点指认替代自我介绍，开口就戳耗时点。", "依据": ["口播稿"] }
{ "项": "结尾", "评价": "信息", "结论": "留下模板领取方式，属主动交付。", "依据": ["口播稿"] }
{ "项": "论点", "评价": "警示", "结论": "把交付物放在评论区能拉互动，但账号一旦断更，这批人不会再回来找。", "依据": ["评论.聚类.簇", "视频.数据.藏"] }
```

`评价` 三档：`好` = 可借鉴其结构，须用自己的素材改写；`警示` = 搬用会出事；`信息` = 中性判断。

## 六轴与指标

**分值不是抄数值，是「换个账号照抄的可行度」**。`内容轴.切镜每分钟` 是 15 次/分，但这一项打 6 分，因为普通账号做不到每 4 秒一切。

- 六轴必须给全，0–10 整数，不许 null
- 指标允许 null，但**card 里有数据的项不许 null**，`check` 会拦
- 六轴是综合指数，不许只看一两个指标

## 评论簇

card 聚出几簇就写几簇，漏一簇判待补。名 2–6 字，一句话 30 字内，只依据代表句。

```json
{ "簇": 1, "名": "骂礼包", "一句话": "期待被付费礼包浇灭，直接说被恶心到。" }
{ "簇": 2, "名": "刷到路过", "一句话": "从推荐流点进来，只留一句看过了。" }
```

不许用「正向」「讨论」「其他」这类空词，也不许照搬机器关键词。

## 该学的 / 别学的

每条都要能从上面的判断推出来，不能凭空补。

```json
"该学的": ["第一格用体量怼脸，替掉所有铺垫", "切镜密度压住划走，不靠口播留人"]
"别学的": ["纯画面预告把期待拉满，接不住的产品会被评论区反噬"]
```

`下次怎么拍` 写这条如果重拍，具体改哪几步（顺序写），不是泛泛而谈。

## 缺口

写「这次到底缺什么、为什么影响结论」，不是写道歉。

```
- 本条无有效口播：ASR 只出主题曲一句歌词与片尾水印（`口播判定.度量.每分钟`），语速与口播覆盖率本次不评
- 依据是抽帧 + 口播稿，未看完整视频；`画面.帧.间隔秒` 决定了时间粒度，短暂画面可能漏掉
- 没有横向参照：只采了这一条，无法判断同类账号的正常区间
```

## 可用依据指针

| 指针 | 说什么 |
|:--|:--|
| `视频.时长秒` `视频.数据.赞/藏/评/转` `视频.比例.*` | 基本盘与三组比值 |
| `视频.文案` `视频.话题` `视频.章节` | 内容主张与平台章节 |
| `内容轴.语速/口播覆盖率/首句秒/切镜每分钟` | 节奏四项 |
| `密度曲线` `密度统计.均值/最低/最低秒/低洼数/前半/后半` | 口播密度在片中的起伏 |
| `评论.采到` `评论.聚类.水评率` `评论.聚类.分布` `评论.聚类.簇` | 评论质量与主题 |
| `评论.地区Top` `评论.覆盖省级行政区` `评论.时间分布` | 观众地理与到达节奏 |
| `画面.拼图[].文件/帧从/帧到/秒从/秒到` | 拼图与格号换算 |
| `口播判定` | 无有效口播 / 未转写时的判定证据 |

拼图内的格号：`拼图-01.jpg 第 N 格`，N 要在 `帧从`–`帧到` 之间，且这张必须已进 `已看`。
