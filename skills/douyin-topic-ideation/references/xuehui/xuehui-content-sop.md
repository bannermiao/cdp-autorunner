# 薛辉内容创作SOP详解

## 一、完整内容IP策划五步法（3W课程核心）

1. **明确商业定位**：你到底是卖什么的？（先定变现再做内容）
2. **分析目标人群**：他们是谁、他们爱看什么？（用三层人群模型）
3. **用四个万能脚本生产内容**：晒过程、聊观点、讲故事、教知识
4. **用三有原则检验视频**：有趣、有用、有共鸣，确保观众爱看
5. **用三大运营策略运营账号**：多维、原生、高频，实现持续变现

**红线：不要一上来就拍"我的产品有多好"——那是兔子拿胡萝卜钓鱼，你觉得是好东西，鱼根本不爱吃。做视频最忌讳自嗨，必须有用户思维。**

## 二、选题SOP

### 选题公式
**热点 + 基础内容 + 爆款词根 = 选题**

### 选题生成法：加法不是想
选题不是想出来的，是加出来的。任何普通选题加上爆款词根立刻有戏：
- "如何穿搭" → 没人点
- "见丈母娘该怎么穿？" → 有冲突有情绪
- "同学聚会上最丢面子的穿搭有哪些？" → 有画面有代入感
- "第一次去女朋友家，穿错这三件衣服直接减分" → 有恐惧有具体

### 选题黄金配比
- **60% 泛选题**：负责吸流量
- **20% 人设选题**：负责让人喜欢你
- **20% 转化选题**：负责让人信任你并买单

### 素材库建设
- 情绪记录法：每天让自己情绪波动的事都记下来，每个情绪波动对应一个观点，即一个选题
- 高赞作品热评：必是引发大量共鸣的，是选题和素材金矿
- 各平台搜索：抖音、快手、小红书、知乎按领域搜，关注领域优质账号

### 小类目商家选题
- 类目抄赛道：卖排风系统的抄餐饮装修账号选题
- 四个特色元素：产品特色（西安摔碗酒）、经营特色（生蚝开瓶盖）、活动特色（挑战赛）、设计特色（大草原风、露营风）
- 三个创意突围方向：蹭热点、冷门知识、个人IP（创业故事、起伏感悟）

## 三、四个万能脚本（任何赛道直接套用）

### 1. 晒过程——展示真实，建立信任（最易上手）
把做产品/服务的过程拍出来。
- 卖地瓜的拍挖地瓜；开饺子馆的拍买肉调馅；做运营的拍帮粉丝改账号
- 可批量产出：服务一个客户拍一条，100个客户拍100条
- 用户直观感受产品质量好、手艺好，自然信任

### 2. 聊观点——引发共鸣，筛选粉丝
针对赛道热点话题发表自己的看法。观点没有对错，说到一部分人心坎里就能吸引同频精准粉丝。
- 情感号："恋爱的本质是吸引，不是讨好"
- 教育号："孩子学习不好，根源在父母"
- 创业号："抖音创业产能低，是因为大多数人只是来试一试的"

### 3. 讲故事——拉近距离，塑造人设
讲自己的故事或身边人的故事，让人设有血有肉，不是冷冰冰的卖货机器。
- 卖地瓜的铁蛋讲90后返乡创业；火锅店老板讲家里困难但依然努力工作的员工

### 4. 教知识——体现专业，解决问题
分享领域专业知识和技巧，让用户觉得你是专家，有需求第一个想到你。
- 卖家电的教"冰箱到货后为什么不能立马插电"；卖收纳盒的教"如何提升冰箱利用率"
- **注意：知识太浅没人看**。"花洒出水小怎么办？看看是不是堵住了"这种没人看，**要教就得加猎奇**

## 四、创业故事写作法（IP人设核心）

### 核心心法
**塑造敌人 + 塑造羁绊。敌人的作用是让人看，羁绊的作用是让人点赞。**

### 铁律：经典桥段里没有"自己努力"
- 张无忌学九阳神功三年半，电影三个镜头就带过——没人看你的努力，只看你的敌人和羁绊
- 故事要包含反转元素：挫折（被开除）→ 转机（发现商机）→ 逆袭（超越前老板）

### 六步法结构（构建引人入胜的创业故事）
1. **开场定调**：情绪钩子，先抛悬念或反差（"我高考720分，却拒绝了清华"）
2. **塑造敌人**：具体的人或环境（被开除的前老板、看不起你的亲戚）
3. **展示羁绊**：身边真实的人（陪你吃苦的老婆、不离不弃的兄弟）
4. **挫折低谷**：具体到数字和场景（卡里只剩XX块、被多少人拒绝）
5. **转机逆袭**：戏剧性反转，超越敌人
6. **升华收尾**：价值观落点（呼应"愿无知者有力，愿有力者前行"）

### 写作要点
- 一切细节具体化：不说"很惨"，说"卡里只剩73块"
- 不写努力过程，只写结果节点
- 敌人要具体可感，羁绊要真实动人

## 五、脚本类型定式

四维度（讲故事/晒过程/教知识/说观点）+ 三有原则可任意搭配。每种脚本类型有定式：
- 讲故事：弥补遗憾型、寄托物语型、个人成就型
- 大流量型脚本（王小艳模块）：解题型、揭秘型、案例型
- 高变现型脚本（靳兴模块）：客户见证型、场景化脚本、限时福利型

## 六、账号运营三大策略

### 1. 多维
不要只发一种内容。四个脚本都在发（薛辉自己的账号、卖地瓜的铁蛋、卖水饺的大哥共同点）。多维度内容让用户全面了解你、信任你、最终买单。

### 2. 原生
真实不端着。日常生活什么样，拍视频就什么样。越真实距离越近越信任。端着演的视频看起来完美但没有灵魂也很难变现。**原生感是变现账号的灵魂。**

### 3. 高频
经常发作品。用户决策链路：看到→知道→动心犹豫→成交。只有经常出现才能被记住，有需求时第一个想到你。你都不记得昨天刷到的百万播放视频是什么——用户也一样。

## 七、变现SOP

### 好账号标准
人物明显、人物真实——符合这两点的账号有很大变现潜能。

### 交付前置销售漏斗
1. 免费阶段：直播连麦、帮粉丝看号，提供大量一对一诊断
2. 低价阶段：39元入门课（体验锚点）
3. 高价阶段：3W课程、线下大课（两天一夜特训营：定位-脚本-拍摄-变现-投放全链路）

用户付费买的不是未知课程，而是对自己已体验过、被证明有效的方法论的深度投资。

### 实战数据参考
- 单条视频播放量3亿、变现1100万
- 杜哥串店"老板背着老板娘让利顾客"：24小时600万曝光、23.3万点赞
- 美甲学员对比选题：13万粉不变现 → 第一条露脸对比视频当天70万播放 → 290万粉

## 八、执行清单（做一条视频的完整流程）

1. 【定位】这条视频属于60%泛流量/20%人设/20%转化中的哪一类？
2. 【选题】基础内容+哪个爆款元素/词根？套没套选题公式？
3. 【开头】3秒钩子是什么？（点名人群/悬念/观点）有没有"大家好"？
4. 【脚本】四个万能脚本中的哪一类？套没套对应定式？
5. 【检验】三有原则占了几个？
6. 【逐句打分】每句话情绪多少分？抽象词换具体数字了吗？
7. 【执行成本】这条是不是"好执行的事"？30条普通的顶一条难的
8. 【原生】有没有端着？是不是真实的样子？
